# Examples

Twelve parts modeled in build123d, copied unchanged from the build123d repository at version 0.11.1 (`docs/assets/ttt/`), the version this workbench pins. They are solutions to the [Too Tall Toby](https://www.tootalltoby.com) modeling exercises, written by the build123d authors and shared under the Apache License 2.0 (see `LICENSE`).

Each script ends with `show()`, as written for OCP CAD Viewer; the workbench understands it. All but the sheet-metal hanger also check the mass of the part they build, so a script that runs to the end built the right part.

The exercise `ttt-ppp0110` is left out: it fails inside OpenCascade with build123d 0.11.1.
